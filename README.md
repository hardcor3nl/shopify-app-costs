# Shopify App Costs

Monthly plan prices, limits and yearly-equivalent prices for 18 Shopify apps in six categories, each price read from the app's own Shopify App Store listing, plus three example app stacks priced at 100, 500 and 2,000 orders a month. Prices are list prices in USD on monthly billing with free trials ignored. The example stacks are derived by us from the plan data by the rule in METHOD.md.

- Canonical page: https://storecartel.com/shopify-app-cost-calculator/
- Statistics computed from this dataset: https://storecartel.com/shopify-app-cost-statistics/
- Version: 2026-09-28 (the date the data was last checked)
- Publisher: StoreCartel editorial, an independent research publication at https://storecartel.com
- Size: 18 apps, 57 plans

## Source method

Every fact traces to a primary source (vendor, government, or a named independent reviewer) linked in the row it belongs to, with the date it was checked. Values are stored as the source states them; nothing is converted between currencies. Empty or null means the source did not state it or could not be read, never a guess. Read METHOD.md for the full rules and GAPS.md for what is missing. We compile from public pages and do not run our own tests.
